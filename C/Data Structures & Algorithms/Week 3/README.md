# Week 3 Assignments: Advanced Linked List Operations

This folder contains my solutions for the Week 3 Data Structures assignments. The focus of this week is on advanced singly linked list manipulations, including ordered insertions, index-based modifications, and algorithmic traversal techniques (such as the slow/fast pointer method).

## Folder Structure

```text
📁 Week 3
├── 📄 q1.c         # Solution for Question 1
├── 📄 q2.c         # Solution for Question 2
├── 📄 q3.c         # Solution for Question 3
└── 📄 README.md    # Directory documentation
```

## File Index

* **`q1.c`** - **Ordered List & Basic Operations**: Implements ordered insertion without re-sorting the whole list, node deletion by value, counting, and memory clearing.
* **`q2.c`** - **Positional Insertion & Deletion**: Demonstrates adding and removing nodes at specific indices, safely handling edge cases like negative positions or out-of-bounds indices.
* **`q3.c`** - **Middle Node Finder**: Uses the two-pointer (slow and fast) technique to efficiently find the middle element of a linked list in a single memory pass.

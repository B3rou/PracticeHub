# C Programming Assignment

This folder contains my Week 1 C programming solutions. This week covers basic algorithm analysis—calculating Time Cost T(n), Time Complexity O(n), and Space Complexity S(n). The code examples demonstrate simple array manipulation and mathematical control flows (like checking for palindrome numbers).

## Folder Structure

```text
📁 Assignment_Folder
├── 📄 q1.c          # Solution for Question 1
├── 📄 q2.c          # Solution for Question 2
├── 📄 README.md     # Directory documentation

```

## File Descriptions

*   **`q1.c`**: Contains the source code for Question 1, where a 10-element array is defined, populated by the user, and printed to the screen. It also includes the analysis of the algorithm's Time Cost $T(n)$, Time Complexity $O(n)$, and Space Complexity $S(n)$.
*   **`q2.c`**: Contains the source code for Question 2. This program takes an integer input from the user and checks if it is a Palindrome Number by reversing its digits mathematically.

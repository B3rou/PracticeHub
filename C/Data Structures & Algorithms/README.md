# Data Structures & Algorithms in C

Welcome to the Data Structures and Algorithms section of my PracticeHub. This directory tracks my academic progression and hands-on coding exercises as I learn core computer science concepts using the C programming language.

## Directory Index

- 📁 **[Week 1: Basic Algorithms and Big-O](./Week%201)**
  * Introduction to algorithm analysis.
  * Calculating Time Cost $T(n)$, Time Complexity $O(n)$, and Space Complexity $S(n)$.
  * Basic array manipulations and mathematical control flows.

- 📁 **[Week 2: Linked Lists in C](./Week%202)**
  * Implementing singly linked lists.
  * Static vs. dynamic memory allocation (`malloc`, `free`).
  * Core list operations: traversing, searching, inserting, and deleting nodes.

- 📁 **[Week 3: Advanced Linked List Operations](./Week%203)**
  * Advanced singly linked list manipulations.
  * Ordered insertions and index-based modifications.
  * Algorithmic traversal techniques (e.g., slow/fast pointer method for finding the middle node).

- 📁 **[Week 4: Stacks, Queues, and Doubly Linked Lists](./Week%204)**
  * Implementing abstract data types (LIFO Stacks and FIFO Queues).
  * Managing complex bidirectional memory references via Doubly Linked Lists.
  * Building interactive simulations (Music Player, Undo feature, Printer Job Spooler).

## Technologies & Concepts
- **Language:** C
- **Core Concepts:** Big-O Notation, Pointers, Dynamic Memory Management, Linear Data Structures (Singly & Doubly Linked Lists), Stacks (LIFO), Queues (FIFO), Two-Pointer Techniques.

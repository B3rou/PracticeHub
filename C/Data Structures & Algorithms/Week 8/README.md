# Week 8: Midterm Examination Period

This directory represents Week 8 of the academic semester, which was reserved for mid-term examinations. No new practical programming assignments or code submissions were assigned during this week.

## Midterm Review Topics

During this period, theoretical and practical comprehension was evaluated across all foundational data structures covered in Weeks 1–7:

* **Algorithm Analysis:** Big-O notation, Time Cost $ T(n) $, and Space Complexity $ S(n) $.
* **Linear Data Structures:** Dynamic memory management (`malloc`/`free`), Singly Linked Lists, Doubly Linked Lists, Stacks (LIFO), and Queues (FIFO).
* **Hierarchical Data Structures:** Binary Search Trees (BST), recursive search algorithms, tree traversals (Inorder, Preorder, Postorder), and tree height metrics.
